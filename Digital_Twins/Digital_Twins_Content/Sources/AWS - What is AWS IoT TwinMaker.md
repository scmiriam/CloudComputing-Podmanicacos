- **Author/Entity:** AWS IoT TwinMaker User Guide

- **Focus:** Official product documentation
- **Key Quotes:**
  - *"AWS IoT TwinMaker is an AWS IoT service that you can use to build operational digital twins of physical and digital systems."*
  - *"The knowledge graph and connectors together provide a single interface for querying data in disparate locations."*
  - *"AWS IoT TwinMaker is not intended for use in, or in association with, the operation of any hazardous environments or critical systems"*

## Source Summary
1. **Concepts:** workspace (S3 + IAM), entity-component model, scenes (glTF/GLB), tags.
2. **Connectors:** IoT SiteWise and Kinesis Video Streams built in; custom ones through Lambda.
3. **Applications:** Grafana / Amazon Managed Grafana plugin; Mendix partnership.

> [!warning] Lifecycle
> No *maintenance/sunset* notice appeared in the guide or in AWS's *Lifecycle Changes* page (https://docs.aws.amazon.com/general/latest/gr/service-lifecycle.html) when this was checked. AWS did retire related IoT services in 2025-2026.
