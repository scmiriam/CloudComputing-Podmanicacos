## Source Summary
1. **Approach:** low-code/no-code ontology modeling, mapping and contextualization of IT/OT data.
2. **Storage:** OneLake. Data must first be in a Fabric lakehouse.
3. **Extensions:** Power BI, Real-Time Dashboards, Activator, Fabric data agent (generative AI), ML.
4. **Status:** preview, first shown at Microsoft Build 2025. No GA date published.
